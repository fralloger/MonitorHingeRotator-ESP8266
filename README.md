# MonitorHingeRotator-ESP8266
Автоматический поворот мониторов Windows с помощью ESP8266 и BMI160. Поддерживает несколько мониторов и датчиков, настройку смещения и реверса, управление через Wi‑Fi и интерфейс WinUI 3.


# Monitor Hinge Rotator

Monitor Hinge Rotator — система автоматического поворота мониторов в Windows 10/11 на основе датчика положения BMI160 и контроллера ESP8266.

Датчик устанавливается на поворотный монитор и передаёт его положение по Wi‑Fi на компьютер. Программа определяет нужную ориентацию и автоматически поворачивает выбранный монитор средствами Windows.

## Возможности

* автоматическое определение ориентации монитора;
* связь между ESP8266 и компьютером по локальной сети;
* поддержка нескольких мониторов;
* поддержка нескольких независимых ESP8266-нод;
* привязка каждой ноды к определённому монитору;
* отображение показаний датчика, смещения и итоговой ориентации;
* настройка углового смещения;
* реверс направления при установке датчика другой стороной;
* автоматическое сохранение и применение настроек;
* компактный интерфейс на WinUI 3;
* работа в области уведомлений Windows;
* автозапуск вместе с Windows;
* журналирование событий и ошибок;
* установщик для Windows;
* прошивка через Arduino IDE или браузерный ESP Web Tool.

## Оборудование

* Wemos D1 mini на базе ESP8266;
* датчик положения BMI160;
* компьютер с Windows 10 или Windows 11;
* локальная сеть Wi‑Fi.

Проект подходит для мониторов на поворотных креплениях и шарнирах, которые используются как в альбомной, так и в портретной ориентации.
